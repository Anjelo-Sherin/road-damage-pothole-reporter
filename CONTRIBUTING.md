# Contributing to RoadPulse AI

We welcome contributions from the open-source civic tech and computer vision communities!

## Workflow

1. Fork the repository on GitHub (`https://github.com/Anjelo-Sherin/road-damage-pothole-reporter`).
2. Create a feature branch: `git checkout -b feat/your-feature-name`.
3. Commit your changes following conventional commits (`feat:`, `fix:`, `docs:`, `test:`).
4. Run the test suite: `PYTHONPATH=. pytest tests/ -v`.
5. Push to your branch and open a Pull Request.

## Code Standards
- Python code should adhere to PEP 8 standards.
- Maintain type hints where practical.
- Keep tests passing with 100% test coverage for new endpoints or algorithms.
