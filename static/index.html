DBSCAN Spatial Deduplication Architecture

How RoadPulse AI solves the multi-frame duplicate detection problem using scikit-learn DBSCAN with the Haversine metric.

The Challenge: Multi-Frame Flood

A vehicle driving over a single 1-meter pothole at 35 km/h captures 4 to 8 consecutive video frames. A naive classifier outputs 8 separate complaints for the same pothole, overwhelming civic work crews.

The Solution: Haversine DBSCAN

DBSCAN clusters detections with ε = 20 meters. No prior cluster count k is required. It computes the spatial centroid, picks the highest-confidence bounding box as evidence, and aggregates frequency.
